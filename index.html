Қалай жұмыс істейді
  1. Chrome мәзірінен «Басты экранға қосу» / «Установить приложение» — ULDAR GeoFoto иконкасы пайда болады, интернетсіз де ашылады.
  2. Алғаш ашқанда орынға (геолокация) рұқсат беріңіз. Жоғарыдағы белгі жасыл (±5 м-ден жақсы) болғанда түсіріңіз.
  3. Фото не Видео басылғанда телефон камерасы ашылады. Түсіріп, «OK» басыңыз — файл координатпен Downloads (Жүктеулер) папкасына сақталады.
  4. Координат үш жерге жазылады: фотоның EXIF-іне / видеоның метадерегіне, файл атына (_N42.341700_E69.590100) және (қосулы болса) суреттің өзіне.
  5. Әр түсірілімнің жанындағы Google / Yandex / 2GIS сол нүктені картада ашады. «Барлығы Yandex картада» — барлық нүкте нөмірімен (нөмір → тізімдегі уақыт).
  6. Компьютерге USB кабельмен немесе Telegram-да «Файл ретінде» жіберіңіз, сосын AutoCAD-та GEOFOTO командасы (Mgeo) немесе GeoFoto.html.
